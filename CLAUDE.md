# Projekt
Kattintható prototípus Figma designból. Nem production kód.

## Szabályok
- Sima HTML + CSS + minimális vanilla JS, build lépés nélkül
- Egy HTML fájl képernyőnként, közös style.css
- A Figma variables-ből CSS custom property-k (:root)
- Reszponzív: a Figma frame-ek szerinti mobil és desktop breakpoint
- Képek és ikonok az /assets mappába (ikonok SVG-ként)
- Ne találj ki tartalmat vagy stílust, ami nincs a designban
- A navigáció működő linkekkel legyen összekötve
